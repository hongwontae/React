1. redux-saga 파일의 역할, 순서

** saga pattern **
=> 마이크로서비스 환경에서 여러 비동기 작업을 순서대로 처리하고, 실패하면 롤백하는 흐름을 다루는 패턴을 의미
=> redux-saga에서 saga는 액션->비동기 API 요청-> 성공/실패 -> 다른 액션 디스패치 이 하나의 흐름을 의미

1-1. store.js
=> reducer를 등록
=> saga 미들웨어 설정
=> root saga 실행
=> 앱 시작 시 가장 먼저 실행됩니다.

1-2. Slice.js
=> Redux Toolkit의 Slice 정의 파일입니다.
=> createReducer를 통해 reducer와 action을 정의합니다.

1-3. saga.js
=> 실제 API 요청을 처리하는 saga입니다.
=> 액션이 발생하면 yield call()로 API를 요청하고 yield put()으로 결과를 전달합니다.

1-4. rootSaga.js
=> 나중에 여러 saga가 생기면 all([...])으로 한 번에 실행할 수 있습니다.
=> saga의 메인 포인트입니다.
