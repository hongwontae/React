3. store
=> createStore()를 통해서 store를 생성합니다.
=> 첫 번쨰 인자로는 상태, 두 번쨰 인자는 미들웨어를 추가합니다.

4. watcher saga - worker saga - root saga

(call(fn, ...args) -> 함수 호출 제어권을 saga에게 맡기면서 비동기를 호출합니다.)
