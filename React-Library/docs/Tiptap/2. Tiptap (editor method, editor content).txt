1. editor method

1-1. editor.chain()
=> 체이닝을 시작한다.

1-2. editor.chain().focus()
=> 먼저 에디터 포커스를 맞춥니다. (커서가 깜빡입니다.)

1-3. editor.chain().focus().toggleBold()
=> 선택된 텍스트나 추가할 텍스트 대상으로 bold을 적용하거나 푼다.
=> toggle 기반(선택되면 true, 아니면 false)

1-4. editor.chain().focus().toggleBold().run()
=> 지금까지 쌓아온 명령을 한꺼번에 실행한다.


2. editor content 가져오는 방법
=> editor의 content는 html 형식을 갖춘 문자열이 반환됩니다.

2-1. ref
=> ref를 생성하고 <EditorContent ref={editorRef}/>로 연결합니다.
=> editorRef.current.getHTML()로 에디터 데이터를 가져올 수 있습니다.

2-2. state
=> editor 내용을 담을 state를 생성합니다.
=> useEditor({
    onUpdate : ({editor})=>{
        setEditorContent(editor.getHTML())
    }
}) 
// useEditor({onUpdate})는 함수를 값으로 받아 editor 내용이 변경될 때마다 트리거 됩니다.
// onUpdate : ({editor})=>{} editor는 에디터 인스턴스입니다. editor.getHTML()를 통해 내용을 가져올 수 있습니다.
