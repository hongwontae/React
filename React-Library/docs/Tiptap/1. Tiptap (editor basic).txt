1. Tiptap
=> 텍스트 에디터를 쉽게 만들어주는 React 라이브러리입니다.
=> 커스터마이징, 모듈화된 확장기능으로 굵게, 기울임, 링크, 테이블, 이미지 등 추가


2. Tiptap 설치 명령어
=> npm install @tiptap/react @tiptap/starter-kit


3. Tiptap 기본 구성
3-1. Editor : 에디터 인스턴스, 상태 관리하고 명령 실행하는 두뇌 역할
3-2. EditorContent : 실제 HTML 화면에 렌더링하는 컴포넌트
3-3. Extensions : 기능 확장 모듈

** StarterKit **
=> 기본 확장 기능을 손쉽게 추가해줍니다.


4. editor 생성
=> import {useEditor} from '@tiptap/react';
=> import StarterKit from '@tiptap/starter-kit'
4-1. const editor = useEditor({
    extensions : [],
    content : `<p>시작합니다!</p>`
})
4-2. extensions의 배열에 기능을 추가하더라도 textEdtior에서 바로 사용 불가 (기능만 추가한 것입니다.)
=> 기능만 활성화되었을 뿐입니다. UI 버튼이 없기에 직접 만들어서 editor에 명령을 보내야 합니다.


5. 에디터 렌더링
5-1. return (<><EditorContent editor={editor} /></>)
