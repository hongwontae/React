1. Tiptap에서 이미지 추가하는 방법
=> 두 가지 방법이 존재합니다. 
=> 두 방법 모두 설치 -> npm install @tiptap/extension-image

1-1. 이미지 URL 방식
=> editor.chain().focus().setImage({src : url}).run()
=> 해당 메서드 체인으로 에디터에 이미지를 삽입할 수 있습니다.

1-2. 파일 업로드 방식
=> input 태그를 생성해서 click 한 다음 file를 가져옵니다.
=> 이 떄 e.target.files[0]을 state로 저장하고 
=> const url = URL.createObjectURL(file)를 통해 브라우저에서 임시로 보여주는 링크를 가져옵니다.
=> editor...setImage({src : url})로 미리 보여 주면 됩니다.
=> 이렇게 설정하면 백엔드에 보낼 데이터 + 브라우저에서 즉시 보여줄 임시 데이터가 완성됩니다.


2. useEditor의 extensions : []에 추가할 확장 기능은 클래스입니다.
=> 해당 클래스를 확장하여 확장 기능에 추가 가능을 더 하려면 Image.extend({})를 호출하여 반환 값을 넣어야 합니다.

2-1. const CustomImage = Image.extend({
    addAttributes(){ // 속성 추가 메서드
    return {
        ...this.parent?.(), // 기존의 부모 속성을 가져옵니다.
        width : {
            default : '300px',
            parseHTML : element => element.getAttribute('width'),
            renderHTML : attributes => {
                return {
                    width : attributes.width
                }
            }
        },
        height : {
            default : 'auto',
            ....
        }
    }
    }
})

2-2. 속성 추가할 떄 구조 설명
=> 각 속성은 객체 형태로 정의 합니다.
=> default, parseHTML, renderHTML을 설정할 수 있습니다.
=> default : 기본값 설정하는 부분 (input에서 사진을 추가해서 렌더링할 떄 size)
=> parseHTML : HTML에서 데이터를 읽어와 Tiptap에서 사용하는 내부 구조로 변환합니다.
=> renderHTML : Tiptap 내부 구조에서 데이터를 HTML로 변환하여 브라우저에 표시합니다.
